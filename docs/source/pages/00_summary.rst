Introduction
============

=================================
Welcome to this Sphinx Template!
=================================

Hi, I'm Emma! This is a blank, open-source project designed to be cloned by anyone who wants to jumpstart their own online Sphinx documentation.


About this project
------------------

- **The Goal:** Provide a ready-to-use skeleton so you don't have to struggle with the initial setup.

- **The Content:** Inside, you will find a breakdown of how this project was made, along with a few empty documentation examples to guide you.

- **Your Turn:** Once you clone it and start creating your own content, feel free to delete all my previous dummy pages and make it yours!


Behind the Scenes (The Tech Stack)
----------------------------------

If you are curious about how this template was built, here is the quick workflow:

- **Local Dev:** Written in plain text (``.rst`` files) and compiled locally using a Windows Terminal (PowerShell) with Python and Sphinx.

- **Look & Feel:** Styled with the :rainbow:`Furo` theme, upgraded with some custom local CSS (``custom-color.css``) and JavaScript (``custom-click.js``) to fix the sidebar behavior.

- **Automation:** Hosted on GitHub Pages. Every single time a change is pushed, an automated GitHub Actions workflow spins up a Linux server to rebuild and update the website instantly.
